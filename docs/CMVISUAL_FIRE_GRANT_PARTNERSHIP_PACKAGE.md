# CMVisual — Fire-Service Funding & Pilot Partnership Package

## Purpose
Prepare CMVisual for a fire/rescue department to evaluate the technology in a controlled training or validation scenario and, where appropriate, pursue department-led grant funding.

## What the department would evaluate
CMVisual is an evidence-first spatial platform. It combines actual camera observations and validated external sensor observations into one spatial operating picture while preserving source, time, uncertainty and confidence. Measured observations are separated from derived and predicted information.

## Proposed pilot
**Phase 1 — Operational discovery:** 20–30 minute command/crew review of the interface and actual sensor capabilities.

**Phase 2 — Controlled training:** agreed training environment, known participants, known sensor placement, documented ground truth and safety controls.

**Phase 3 — Validation report:** accuracy, latency, coverage, false positives/negatives, sensor conflicts, prediction error, usability and limitations.

**Phase 4 — Funding case:** if useful, convert measured pilot outcomes into a department-owned technology/equipment/training proposal for an appropriate funding program.

## Department value questions
- Does the system improve spatial awareness?
- Does it reduce time required to understand available sensor information?
- Does it help command identify verified observations and their source?
- Does it make uncertainty visible instead of hiding it?
- Does replay improve after-action review and training?
- Can multiple authorized devices be aligned into one shared operational frame?
- What information is useful enough to justify deployment cost?

## Grant strategy
USFA identifies FEMA fire-service grant programs including AFG, SAFER and FP&S. Program windows and eligibility vary by fiscal year, so current NOFOs must be checked before any submission. FP&S has historically supported firefighter safety research and technology/product development, making it a potentially relevant route for a qualified research/development project.

A department should not be told that a CMVisual purchase is automatically grant-eligible. Instead, the department, its grant administrator and the current NOFO should determine eligibility and allowable costs.

## Evidence package to collect
- Pilot objectives.
- Department operational problem statement.
- Current workflow baseline.
- Sensor inventory.
- Training scenario and ground truth.
- Measured performance metrics.
- Limitations and failure cases.
- Safety/privacy controls.
- Procurement estimate.
- Training/support requirements.
- Sustainability plan.
- Letters of support if appropriate.

## Outreach position
Do not ask a department to buy an unproven system. Ask for a controlled evaluation and operational feedback first. A successful evaluation can become evidence for a later procurement, grant, research partnership or larger pilot.

## Current resource note
USFA's fire-service grants page remains the authoritative starting point for federal fire-service funding resources. Current application periods must be verified at the time of submission.
